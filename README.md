# Reproducibility Materials

This repository contains code for the submitted manuscript.

## Contents

- `Section_5.1_code/`: code for Section 5.1
- `Section_5.2_code/`: code for Section 5.2
- `Supplement code/`: code for the supplement
- `DSP-MFSV-CAPM.R`: main R script

## How to run

Open the relevant R scripts and run them in R or RStudio.

The code is provided to help reviewers understand and reproduce the analyses in the manuscript.
